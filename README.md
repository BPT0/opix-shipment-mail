# 오픽스 출고 정보 메일 생성기

출고 정보를 입력하면 Outlook용 메일 제목·수신인·참조·내용을 자동으로 만들어 주는 단일 HTML 페이지입니다.

## 사용법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 빌드나 서버가 필요 없습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 마크업 |
| `css/style.css` | 스타일 |
| `js/config.js` | 설정값 (버전, 전달방식, 출고품목, 계약 방식, 스니펫 그룹, 서비스태그 규칙) |
| `js/logic.js` | 화면과 무관한 순수 함수 (부서 추출, 기번 검증, 수신인 파싱) |
| `js/dom.js` | DOM 헬퍼, 토스트, 클립보드 복사 |
| `js/storage.js` | 브라우저 `localStorage` 저장 (오픽스 버전, 스니펫) |
| `js/render.js` | 입력값으로 제목·본문·수신인을 만들어 화면에 그리는 `render()` |
| `js/snippets-ui.js` | 수신인·참조인 스니펫 등록 화면 |
| `js/main.js` | 초기 UI 구성과 이벤트 연결 |

스크립트는 `file://`로 열어도 동작하도록 ES 모듈이 아닌 일반 스크립트로 `index.html`에서 위 순서대로 불러옵니다.

## 참고

- 수신인·참조인 스니펫과 추가한 오픽스 버전은 브라우저 `localStorage`에 저장됩니다.
- 품목 코드, 서비스태그 규칙, 계약 방식 등 설정은 `js/config.js`에서 수정합니다.
